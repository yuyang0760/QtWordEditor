### 修复内容：修复无限循环问题
#### 1. 问题分析
- 打字后程序卡死，控制台无限循环
- 原因：TextBlockItem::safeUpdateLayout() 会再次调用 MathItem::updateLayout()
- 形成调用链循环：
  - GenericMathSpan → GenericMathItem::updateLayout() → notifyParentLayoutChanged()
  - → FractionItem::updateLayout() → notifyParentLayoutChanged()
  - → TextBlockItem::safeUpdateLayout() → 遍历 m_mathItems → 再次调用 MathItem::updateLayout()
  - 无限循环！！！

#### 2. 修复方案
- 修改 TextBlockItem::safeUpdateLayout()
- 移除“第一步：递归更新所有 MathItem 的布局”
- 因为 MathItem 已经通过 notifyParentLayoutChanged() 调用链更新过了！
- 这样就不会形成循环了

### 修复内容：修复公式变宽后覆盖后面文本的问题
#### 1. 问题分析
- 公式可以打字了，但是打字后公式会变宽，会覆盖后面的文本字符
- 原因：notifyParentLayoutChanged() 只通知父 MathItem，没有通知 TextBlockItem
- 导致 TextBlockItem 不知道公式尺寸变化，没有重新布局整个段落

#### 2. MathItem::notifyParentLayoutChanged() 修改
- 修改该方法，在没有父 MathItem 时：
  - 向上遍历 QGraphicsItem 层次结构
  - 查找类型为 TextBlockItem（Type = UserType + 1001）的项
  - 找到后调用 TextBlockItem::safeUpdateLayout() 重新布局整个段落
- 这样 TextBlockItem 就会知道公式尺寸变化，并重新布局后面的文本

#### 3. 程序验证
- 现在打字后公式变宽，后面的文本会自动向后移动
- 不会出现文本被覆盖的情况
- 整个段落的布局会正确更新

### 技术实现：
1. 坐标路径构建
```cpp
// 从点击的 MathItem 向上遍历，收集路径
MathItem *currentItem = mathItem;
QList<MathItem *> itemPath;
while (currentItem) {
    itemPath.prepend(currentItem);
    currentItem = currentItem->parentMathItem();
}

// 从根到点击的 MathItem 构建路径
QPointF currentLocalPos = scenePos;
for (int i = 0; i < itemPath.size(); ++i) {
    MathItem *container = itemPath[i];
    currentLocalPos = container->mapFromScene(currentLocalPos);
    
    // 调用 hitTestRegion 判断点击的是哪个子区域
    int childIndex = container->hitTestRegion(currentLocalPos);
    
    if (childIndex >= 0) {
        // 添加路径段
        PathSegment segment(container, childIndex, 0);
        mathPath.push(segment);
        
        // 如果有子元素，继续转换坐标到子元素的局部坐标
        MathItem *childItem = container->childAt(childIndex);
        if (childItem) {
            currentLocalPos = childItem->mapFromItem(container, currentLocalPos);
        }
    }
}
```

if (m_wrapMode == WrapMode::NoWrap) {
