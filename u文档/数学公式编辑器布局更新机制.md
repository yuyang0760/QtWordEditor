# 数学公式编辑器布局更新机制

## 1. 核心问题分析

### 1.1 宽度变化影响
当在公式中输入字符时，会导致以下宽度变化：
- **数字/变量项**：输入字符增加文本长度，导致NumberItem宽度增加
- **容器项**：子项宽度变化会导致RowContainerItem、FractionItem等容器宽度变化
- **嵌套影响**：嵌套公式的宽度变化会向上传递，影响父容器布局

### 1.2 高度变化影响
当在公式中输入字符时，会导致以下高度变化：
- 插入大型运算符（如∑、∫）
- 插入分数、根号等复杂公式
- 改变字体大小或样式

这些变化会影响整个行的行高，需要动态调整。

## 3. 行高计算机制

### 3.1 行高计算逻辑
```cpp
// TextBlockLayoutEngine中的行高计算
void TextBlockLayoutEngine::layout()
{
    qreal currentLineHeight = 0;
    for (int i = 0; i < m_paragraphBlock->inlineSpanCount(); ++i) {
        InlineSpan* span = m_paragraphBlock->inlineSpan(i);
        qreal spanHeight, spanBaseline;
        calculateSpanMetrics(span, spanHeight, spanBaseline);
        
        // 更新当前行高为最大值
        if (spanHeight > currentLineHeight) {
            currentLineHeight = spanHeight;
        }
    }
    
    // 设置行高
    m_currentLine.height = currentLineHeight;
}
```

### 3.2 公式高度计算
```cpp
// MathFormulaItem中的高度计算
void FractionItem::updateLayout()
{
    // 计算分子和分母的高度
    m_numerator->updateLayout();
    m_denominator->updateLayout();
    
    // 计算分数整体高度
    qreal numeratorHeight = m_numerator->boundingRect().height();
    qreal denominatorHeight = m_denominator->boundingRect().height();
    qreal lineHeight = 2;  // 分数线高度
    
    m_boundingRect.setHeight(numeratorHeight + lineHeight + denominatorHeight);
    m_baseline = numeratorHeight + lineHeight;  // 基线位置
}
```

### 3.3 基线对齐机制
```cpp
// 确保所有内联元素基线对齐
void TextBlockLayoutEngine::addToCurrentLine(InlineSpan* span)
{
    qreal spanHeight, spanBaseline;
    calculateSpanMetrics(span, spanHeight, spanBaseline);
    
    // 更新行高为最大值
    if (spanHeight > m_maxLineHeight) {
        m_maxLineHeight = spanHeight;
    }
    
    // 计算元素的垂直位置（基于基线）
    qreal yOffset = m_maxLineHeight - spanBaseline;
    m_currentLine.spanRects.append(QRectF(currentX, yOffset, spanWidth, spanHeight));
}
```

## 4. 自动换行处理

### 4.1 自动换行逻辑
```cpp
void TextBlockLayoutEngine::layout()
{
    qreal currentLineWidth = 0;
    for (int i = 0; i < m_paragraphBlock->inlineSpanCount(); ++i) {
        InlineSpan* span = m_paragraphBlock->inlineSpan(i);
        qreal spanWidth = calculateSpanWidth(span);
        
        if (currentLineWidth + spanWidth > availableWidth && currentLineWidth > 0) {
            createNewLine();  // 自动换行
            currentLineWidth = 0;
        }
        
        addToCurrentLine(span);
        currentLineWidth += spanWidth + m_charSpacing;
    }
}
```

void NumberItem::updateLayout()
{
    if (m_cachedText == m_span->text()) {
        return;  // 文本未变化，使用缓存
    }
    
    // 重新计算尺寸
    QFontMetricsF fm(m_font);
    m_boundingRect = fm.boundingRect(m_span->text());
    m_baseline = fm.ascent();
    m_cachedText = m_span->text();

## 6. 总结

该数学公式编辑器通过以下机制实现了动态布局更新：
1. **信号通知**：内容变化时发出信号，触发布局更新
2. **递归更新**：从变化的子项向上递归通知父项布局变化
3. **行高计算**：始终以行内最高元素的高度作为行高
4. **基线对齐**：确保所有内联元素在同一行内基线对齐
5. **自动换行**：当行宽不足时自动换行
6. **性能优化**：通过局部更新、批量更新和缓存机制提高性能

这种机制确保了公式编辑过程中的实时布局更新，保持了文档的排版一致性和美观性，符合专业数学文档的排版规范。
