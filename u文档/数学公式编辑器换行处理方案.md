# 数学公式编辑器换行处理方案

## 1. 核心原则
- 换行是**段落级操作**，而非内联元素操作
- 公式作为内联元素，不会跨段落存在
- 换行操作会将当前段落拆分为两个独立段落

## 2. 手动换行处理

### 2.1 光标位置定位
统一光标 `UnifiedCursor` 需要获取以下信息：
- 当前所在的 `ParagraphBlock`
- 光标所在的 `InlineSpan` 索引
- 在该 `InlineSpan` 内的字符偏移位置

### 2.2 段落拆分逻辑
```cpp
// 伪代码示例
ParagraphBlock* currentBlock = cursor->currentParagraphBlock();
int spanIndex = cursor->currentInlineSpanIndex();
int charOffset = cursor->currentCharOffset();

// 创建新段落
ParagraphBlock* newBlock = currentBlock->clone();

// 处理当前段落
if (charOffset == 0) {
    // 光标在行首，直接创建空段落
    currentBlock->clearInlineSpans();
} else if (charOffset == currentBlock->length()) {
    // 光标在行尾，新段落为空
    newBlock->clearInlineSpans();
} else {
    // 拆分中间的InlineSpan
    InlineSpan* span = currentBlock->inlineSpan(spanIndex);
    if (span->type() == InlineSpan::Text) {
        TextSpan* textSpan = static_cast<TextSpan*>(span);
        QString leftText = textSpan->text().left(charOffset);
        QString rightText = textSpan->text().mid(charOffset);
        
        // 更新原段落
        textSpan->setText(leftText);
        // 移除后面的所有Span
        for (int i = currentBlock->inlineSpanCount() - 1; i > spanIndex; --i) {
            currentBlock->removeInlineSpan(i);
        }
        
        // 更新新段落
        newBlock->clearInlineSpans();
        TextSpan* newTextSpan = new TextSpan(rightText, textSpan->style());
        newBlock->addInlineSpan(newTextSpan);
        // 添加后面的所有Span到新段落
        for (int i = spanIndex + 1; i < currentBlock->inlineSpanCount(); ++i) {
            newBlock->addInlineSpan(currentBlock->inlineSpan(i)->clone());
        }
    } else if (span->type() == InlineSpan::Math) {
        // 公式作为单个字符处理，光标在公式前或后
        if (charOffset == 0) {
            // 光标在公式前，公式留在新段落
            currentBlock->removeInlineSpan(spanIndex);
            newBlock->clearInlineSpans();
            newBlock->addInlineSpan(span->clone());
            // 添加后面的所有Span到新段落
            for (int i = spanIndex + 1; i < currentBlock->inlineSpanCount(); ++i) {
                newBlock->addInlineSpan(currentBlock->inlineSpan(i)->clone());
                currentBlock->removeInlineSpan(i);
            }
        } else {
            // 光标在公式后，公式留在原段落
            newBlock->clearInlineSpans();
            // 添加后面的所有Span到新段落
            for (int i = spanIndex + 1; i < currentBlock->inlineSpanCount(); ++i) {
                newBlock->addInlineSpan(currentBlock->inlineSpan(i)->clone());
                currentBlock->removeInlineSpan(i);
            }
        }
    }
}

// 插入新段落到文档
document->insertBlockAfter(currentBlock, newBlock);

// 移动光标到新段落开头
cursor->moveToBlockStart(newBlock);
```

### 2.3 视图层更新
- `TextBlockItem` 会监听 `ParagraphBlock` 的变化，自动更新布局
- 新段落会创建对应的 `TextBlockItem` 并添加到 `PageItem` 中

### 2.4 撤销/重做支持
- 将段落拆分操作封装为 `SplitParagraphCommand`
- 记录拆分前后的段落状态，支持撤销（合并段落）和重做（重新拆分）

## 3. 自动换行处理

### 3.1 核心原则
- 自动换行是**布局级操作**，由 `TextBlockLayoutEngine` 统一处理
- 公式作为内联元素，不会被拆分跨多行显示
- 自动换行只会在文本之间或文本与公式之间发生

### 3.2 自动换行算法
```cpp
// 伪代码示例
void TextBlockLayoutEngine::layout() {
    qreal currentLineWidth = 0;
    qreal availableWidth = m_textBlockItem->width();
    
    for (int i = 0; i < m_paragraphBlock->inlineSpanCount(); ++i) {
        InlineSpan* span = m_paragraphBlock->inlineSpan(i);
        qreal spanWidth = calculateSpanWidth(span);
        
        if (currentLineWidth + spanWidth > availableWidth && currentLineWidth > 0) {
            // 需要自动换行
            createNewLine();
            currentLineWidth = 0;
        }
        
        // 添加到当前行
        addToCurrentLine(span);
        currentLineWidth += spanWidth + m_charSpacing;
    }
}

qreal TextBlockLayoutEngine::calculateSpanWidth(InlineSpan* span) {
    if (span->type() == InlineSpan::Text) {
        TextSpan* textSpan = static_cast<TextSpan*>(span);
        return calculateTextWidth(textSpan->text(), textSpan->font());
    } else if (span->type() == InlineSpan::Math) {
        // 公式作为整体计算宽度
        MathSpan* mathSpan = static_cast<MathSpan*>(span);
        return mathSpan->width();
    }
    return 0;
}
```

### 3.3 特殊情况处理
#### 3.3.1 公式宽度超过行宽
- 若单个公式宽度超过可用行宽，自动换行到新行
- 公式居中显示或左对齐（根据段落样式）

#### 3.3.2 行首公式
- 自动换行后行首出现公式时，保持公式完整性
- 避免将公式拆分跨多行

#### 3.3.3 行尾公式
- 若行尾剩余空间不足以显示公式，自动换行到新行
- 确保公式作为整体显示

### 3.4 视图层更新
- `TextBlockItem` 根据布局结果创建多行文本和公式
- 保持所有内联元素的基线对齐
- 处理行间距和段落间距

## 4. 特殊情况处理

### 4.1 公式内部换行
- 公式作为内联元素，内部不支持换行
- 若用户在公式内部按下Enter键，将光标移动到公式后方并执行换行

### 4.2 空段落处理
- 确保新创建的段落至少包含一个空的 `TextSpan`，避免段落为空

### 4.3 格式继承
- 新段落继承原段落的 `ParagraphStyle`
- 内联元素保持原有样式不变

## 5. 与现有架构的兼容性
- 保留原有的 `Span` 接口以兼容旧代码
- 新的 `InlineSpan` 系统与旧系统并行工作，逐步迁移
