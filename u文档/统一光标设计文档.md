# 统一光标设计文档

## 1. 核心原则
- **单一光标**：整个编辑器中只有一个光标，同时处理文本和公式
- **无缝切换**：光标可以在文本和公式之间自由移动
- **所见即所得**：光标位置与用户看到的视觉位置完全一致

## 2. 设计思路

### 2.1 光标状态管理
```cpp
// 光标状态结构体
struct CursorState {
    ParagraphBlock* paragraph;    // 当前段落
    int spanIndex;                // 当前InlineSpan索引
    int charOffset;               // 在Span内的字符偏移
    bool isMath;                  // 是否在公式内
    MathSpan* mathSpan;           // 当前公式Span
    int mathChildIndex;           // 公式内子项索引
};
```

### 2.3 光标移动逻辑
```cpp
void UnifiedCursor::moveRight()
{
    if (m_state.isMath) {
        // 在公式内移动
        if (m_state.mathChildIndex < m_state.mathSpan->childCount() - 1) {
            m_state.mathChildIndex++;
        } else {
            // 移动到公式后的文本
            int nextSpanIndex = m_state.spanIndex + 1;
            if (nextSpanIndex < m_state.paragraph->inlineSpanCount()) {
                m_state.isMath = false;
                m_state.spanIndex = nextSpanIndex;
                m_state.charOffset = 0;
            }
        }
    } else {
        // 在文本内移动
        InlineSpan* span = m_state.paragraph->inlineSpan(m_state.spanIndex);
        if (m_state.charOffset < span->length() - 1) {
            m_state.charOffset++;
        } else {
            // 移动到下一个Span
            int nextSpanIndex = m_state.spanIndex + 1;
            if (nextSpanIndex < m_state.paragraph->inlineSpanCount()) {
                m_state.spanIndex = nextSpanIndex;
                m_state.charOffset = 0;
                
                // 如果是公式，进入公式内
                if (span->type() == InlineSpan::Math) {
                    m_state.isMath = true;
                    m_state.mathSpan = static_cast<MathSpan*>(span);
                    m_state.mathChildIndex = 0;
                }
            }
        }
    }
    
    updateCursor();
}
```

### 2.4 光标渲染
```cpp
void UnifiedCursor::updateCursor()
{
    if (!m_cursorItem) {
        m_cursorItem = new QGraphicsLineItem();
        m_cursorItem->setPen(QPen(Qt::black, 1));
        m_view->scene()->addItem(m_cursorItem);
    }
    
    // 计算光标位置
    QPointF pos;
    qreal height;
    
    if (m_state.isMath) {
        // 在公式内，获取公式内光标位置
        MathFormulaItem* formulaItem = m_view->findMathFormulaItem(m_state.mathSpan);
        if (formulaItem) {
            pos = formulaItem->cursorPosition(m_state.mathChildIndex);
            height = formulaItem->cursorHeight();
        }
    } else {
        // 在文本内，获取文本光标位置
        TextFragment* fragment = m_view->findTextFragment(m_state.paragraph->inlineSpan(m_state.spanIndex));
        if (fragment) {
            pos = fragment->cursorPosition(m_state.charOffset);
            height = fragment->cursorHeight();
        }
    }
    
    // 设置光标位置
    m_cursorItem->setLine(pos.x(), pos.y(), pos.x(), pos.y() + height);
}
```

## 3. 关键技术点

### 3.1 避免双光标问题
- 统一光标类管理所有光标状态
- 只有一个QGraphicsLineItem作为光标图形项
- 光标位置根据当前状态动态计算

### 3.2 公式内光标定位
```cpp
// 在MathFormulaItem中实现光标定位
QPointF MathFormulaItem::cursorPosition(int childIndex)
{
    if (childIndex < 0 || childIndex >= childCount()) {
        return QPointF();
    }
    
    MathFormulaItem* child = childAt(childIndex);
    QPointF childPos = child->pos();
    
    // 根据公式类型计算光标位置
    if (mathType() == Fraction) {
        FractionItem* fraction = static_cast<FractionItem*>(this);
        if (childIndex == 0) { // 分子
            return childPos + QPointF(0, fraction->numerator()->baseline());
        } else { // 分母
            return childPos + QPointF(0, fraction->denominator()->baseline());
        }
    } else if (mathType() == RowContainer) {
        // 行容器内光标位置
        return childPos + QPointF(0, child->baseline());
    }
    
    return childPos;
}
```

### 3.3 文本内光标定位
```cpp
// 在TextFragment中实现光标定位
QPointF TextFragment::cursorPosition(int charOffset)
{
    QFontMetricsF fm(m_font);
    QString text = m_text.left(charOffset);
    qreal x = fm.horizontalAdvance(text);
    qreal y = m_baseline;
    
    return QPointF(x, y);
}
```

## 4. 字符插入实现

### 4.1 输入法处理
```cpp
// 在DocumentView中处理输入法事件
void DocumentView::inputMethodEvent(QInputMethodEvent* event)
{
    if (event->commitString().isEmpty()) {
        // 输入法正在组合字符
        m_cursor->updateCursor();
        return;
    }
    
    // 提交组合字符
    m_cursor->insertText(event->commitString());
}

// 重写inputMethodQuery
QVariant DocumentView::inputMethodQuery(Qt::InputMethodQuery query) const
{
    if (query == Qt::ImCursorPosition) {
        // 返回光标位置
        return m_cursor->state().charOffset;
    } else if (query == Qt::ImCurrentText) {
        // 返回当前文本
        if (m_cursor->isInMath()) {
            return QString();
        } else {
            TextSpan* textSpan = static_cast<TextSpan*>(m_cursor->state().paragraph->inlineSpan(m_cursor->state().spanIndex));
            return textSpan->text();
        }
    }
    return QGraphicsView::inputMethodQuery(query);
}
```

### 4.2 统一插入逻辑
```cpp
void UnifiedCursor::insertText(const QString& text)
{
    if (m_state.isMath) {
        // 在公式内插入字符
        MathSpan* mathSpan = m_state.mathSpan;
        MathSpan* child = mathSpan->childAt(m_state.mathChildIndex);
        
        if (child->mathType() == Number) {
            NumberMathSpan* numberSpan = static_cast<NumberMathSpan*>(child);
            numberSpan->appendChar(text);
        } else {
            // 在公式内插入新的NumberMathSpan
            NumberMathSpan* numberSpan = new NumberMathSpan(text);
            mathSpan->insertChild(m_state.mathChildIndex, numberSpan);
            m_state.mathChildIndex++;
        }
    } else {
        // 在文本内插入字符
        TextSpan* textSpan = static_cast<TextSpan*>(m_state.paragraph->inlineSpan(m_state.spanIndex));
        textSpan->insert(m_state.charOffset, text);
        m_state.charOffset += text.length();
    }
    
    // 更新布局
    m_view->updateLayout();
    updateCursor();
}
```

// 在TextSpan中优化汉字插入
void TextSpan::insert(int position, const QString& text)
{
    // 处理汉字插入
    m_text.insert(position, text);
    
    // 重新计算字体
    m_font = createFontFromStyle(m_style);
    
    // 通知布局更新
    emit contentChanged();
}

// 在NumberMathSpan中优化汉字插入
void NumberMathSpan::appendChar(const QString& text)
{
    // 支持汉字作为变量名
    m_text.append(text);
    emit textChanged(m_text, m_text);
}

## 5. 与编辑器集成
```cpp
// 在DocumentView中使用统一光标
void DocumentView::keyPressEvent(QKeyEvent* event)
{
    switch (event->key()) {
    case Qt::Key_Left:
        m_cursor->moveLeft();
        break;
    case Qt::Key_Right:
        m_cursor->moveRight();
        break;
    case Qt::Key_Up:
        m_cursor->moveUp();
        break;
    case Qt::Key_Down:
        m_cursor->moveDown();
        break;
    case Qt::Key_Backspace:
        m_cursor->backspace();
        break;
    case Qt::Key_Delete:
        m_cursor->deleteChar();
        break;
    default:
        if (event->text().isEmpty()) {
            QGraphicsView::keyPressEvent(event);
        } else {
            m_cursor->insertText(event->text());
        }
    }
}
```
